# سامانه رزرو بلیط اتوبوس 🚌
این پروژه یک سیستم مدیریت و رزرو آنلاین بلیط اتوبوس است که با استفاده از Django توسعه یافته است.

## قابلیت‌ها:
- مشاهده لیست سفرهای موجود
- مشاهده جزئیات سفر و صندلی‌های خالی
- مدیریت اتوبوس‌ها و سفرها از طریق پنل ادمین

## تکنولوژی‌های استفاده شده:
- Python 3.x
- Django Framework
- SQLite (Database)
- Git/GitHub (Version Control)

## ساختار دیتابیس (مدل‌ها):
- BusType: تعریف نوع اتوبوس و تعداد صندلی‌ها
- Trip: تعریف سفرها (مبدا، مقصد، زمان حرکت)
- Booking: مدیریت رزروها
- Passenger: اطلاعات مسافران و شماره صندلی
